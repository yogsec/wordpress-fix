# wordpress-fix

WordPress Vulnerability Scanner - A tool to find and fix security vulnerabilities in WordPress websites.

## Features

- WordPress Version Detection
- Plugin Vulnerability Scanner
- Theme Vulnerability Scanner
- User Enumeration Detection
- XML-RPC Security Scanner
- SQL Injection Testing
- XSS Vulnerability Scanner
- Directory Listing Check
- Backup File Scanner
- Security Headers Check
- Brute Force Protection Test
- Real-time Output

## Requirements

- Python 3.7+
- pip

## Installation

```bash
git clone https://github.com/yourusername/wordpress-fix.git
cd wordpress-fix
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python setup.py
```

Usage
Basic scan:

```bash
python main.py https://example.com
```
